# Reference material (not yet applied to any build)

Files here are captured for internalisation only, per instruction — nothing in this folder has

## `visitsabah-homepage-skywork-prompt.md` + `visitsabah-homepage-reference.html`

A homepage generated by a different AI tool (Skywork), working from a detailed "God Mode" design
brief, under the old working name **VisitSabah.net**. The user likes this **layout** — particularly
the **header and footer architecture** — and wants it followed for all future builds.

### What to reuse — structure/layout

- **Header (3-tier):**
  1. Conditional CMS-controlled alert bar (dismissible, collapses when no active alert)
  2. Utility bar — left: short gateway descriptor, Explore Map, Saved Trip (with count badge),
     Current Alerts; right: Accessibility control, Search, language selector (flag + code
     collapsed, full names expanded)
  3. Main header — logo left, 8-item primary nav center, "Build My Trip"-style primary CTA right,
     mobile menu button
  - Sticky on scroll, compacts/adds shadow after ~100px scroll
- **Footer (5-column grid):** brand column (logo + descriptor + one-line mission) + 4 link groups
  (Discover / Plan / Programmes / Visitor Support) → an official-agency external-links row
  (external-link icon convention: ` ↗`) → bottom row (legal links, language switcher, centered
  copyright with dynamic year)
- **Mobile:** compact header, full drawer (accordion per nav area), 5-item bottom nav bar
  (Discover / Map / Plan / SET / Saved, icon + label, never icon-only), floating "Ask Sabah"
  control repositioned above the bottom nav (never overlapping it)
- **15-section homepage sequence** (hero → visitor intent quick-start → Five Wonders → featured
  destinations → things to do → interactive map → itineraries/Build My Trip → VSY2027 →
  SET → STEP partners → events → stories → plan-with-confidence → responsible travel/trust →
  Ask Sabah prompt) — matches the IA in `docs/gosabah-project-brief.md` and can be treated as the
  homepage's section rhythm.
- Content/image/CMS/accessibility governance rules in the prompt (no fabricated events/fees/dates,
  every image needs rights+credit+alt+focal point, WCAG 2.2 AA, CMS-annotation conventions) are
  consistent with and reinforce `docs/gosabah-project-brief.md` §9–10.

**When this layout is actually built:** keep the header/footer/section *structure and behaviour*
described above, but re-skin it with the approved GoSabah.com palette, type system and real logo,
and rename every VisitSabah.net reference to GoSabah.com (nav items, footer links, copyright line,
meta tags, alt text, etc.) — consistent with the rename already applied throughout
`docs/gosabah-sitemap.json` and `docs/gosabah-project-brief.md`.
